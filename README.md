# Asignacion-Asientos-CSharp
# Asignación de Asientos en un Parque de Diversiones

## Descripción

Este proyecto fue desarrollado para la asignatura **Estructura de Datos** de la Universidad Estatal Amazónica.

El sistema simula la asignación de 30 asientos para una atracción utilizando la estructura de datos **Queue (Cola)** y el paradigma de **Programación Orientada a Objetos** en C#.

Cada visitante recibe un asiento respetando el orden de llegada (FIFO).

---

## Objetivo

Aplicar la estructura de datos Cola para resolver un problema real mediante Programación Orientada a Objetos.

---

## Funcionalidades

- Registrar personas.
- Visualizar cola.
- Asignar asientos.
- Mostrar asientos vendidos.
- Reportería.
